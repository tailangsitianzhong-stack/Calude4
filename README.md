# Planet Pioneer

Godot 4.5で作っている、宇宙・惑星開拓ゲームの試作です。球体の惑星の地表を歩いて資源を集め、基地を建てます。

## 遊び方

- 左側をなぞる:移動(PCではWASDか矢印キー)
- 右側をドラッグ:視点を回す(PCではマウスでドラッグ)
- ボタン:ジャンプ(Space)/採取(E)/採掘機(1)/ドーム(2)
- 目標:居住ドームを建てて入植者を20人にする

## 構成

| ファイル | 内容 |
|---|---|
| `scripts/planet.gd` | キューブスフィアとノイズで作る球体の惑星、海、大気 |
| `scripts/player.gd` | 惑星の中心へ向かう重力で歩くプレイヤーとカメラ |
| `scripts/touch_controls.gd` | スマホ用のスティック、視点ドラッグ、ボタン |
| `scripts/main.gd` | 資源、建物、昼夜、画面表示などゲーム全体 |
| `web/shell.html` | スマホのブラウザで遊ぶための読み込みページ |
| `tools/build_web.sh` | Web版を書き出して `build/artifact/` にまとめる |
| `tools/make_font.py` | 使っている文字だけを含む日本語フォントを作る |

画面に出す日本語を増やしたら `tools/make_font.py` でフォントを作り直してください(作り直さないと新しい文字が表示されません)。

## PCで開く場合

Godot 4.5以降で `project.godot` を開けば、そのまま編集・実行できます。
